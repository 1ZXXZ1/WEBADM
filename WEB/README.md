# Samba AD Panel — Документация проекта

## Обзор проекта

**Samba AD Panel** — это веб-панель управления для Samba Active Directory Domain Controller. Приложение предоставляет графический интерфейс для администрирования домена Samba AD DC через взаимодействие с Python/FastAPI бэкендом по REST API.

- **Версия фронтенда:** 1.1.6
- **Версия API:** pr-a-1.4
- **Стек:** Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui + Zustand + Prisma (SQLite) + Axios + i18next

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Настроить .env
cp .env.example .env

# 3. Запустить в режиме разработки
npm run dev

# 4. Открыть http://localhost:3000
```

## Ключевые возможности

- **Управление пользователями AD** — создание, редактирование, удаление, сброс паролей
- **Управление группами** — CRUD операции, управление членством
- **Управление компьютерами** — учётные записи компьютеров
- **Управление контактами** — контакты AD
- **Подразделения (OU)** — организационная структура
- **DNS управление** — зоны и записи DNS
- **Групповые политики (GPO)** — просмотр и управление
- **Информация о домене** — FSMO роли, уровни функциональности, политика паролей
- **Shell терминал** — выполнение bash/python3 команд на сервере
- **Shell Projects** — рабочие пространства с проектами
- **ETL конвейер** — визуальный конструктор пакетных операций
- **AI Ассистент** — помощь в построении конвейеров через естественный язык
- **AI Агент** — автономное выполнение API-операций
- **Аудит** — просмотр журналов аудита
- **Управление** — управление API-пользователями и ключами
